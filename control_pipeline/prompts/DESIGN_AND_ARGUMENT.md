# Design and argument prompt specifications

These reusable specifications express the assignment's design and argument tasks. They were assembled from the assignment requirements to support reproduction and review. The implementation and report were developed with AI assistance under student direction.

## Pipeline design specification

Design and implement a process control pipeline for AI-assisted development of the Zombie Game Simulation Framework using an ontology. A simplified demonstration must retain nontrivial agent behavior.

Explicitly state each step of the pipeline and explain its purpose, inputs, outputs and acceptance conditions. Define the game concepts, relationships and constraints in a machine-readable ontology. Explain where the ontology guides generation and where executable checks enforce it. Include a failure-feedback and correction path, and preserve intermediate results.

Provide runnable code and instructions for the demonstrations. Preserve the exact operational prompts, candidate responses, generated artifacts, ontology snapshots and results needed to inspect each stage.

## Written argument specification

Explain which aspects of AI-assisted development the pipeline controls and improves, and why each control is effective. Compare a workflow that accepts compiling code with a workflow that requires ontology validation, task fidelity and runtime checks before acceptance.

For every main claim, connect the failure mode, the control and a concrete measured outcome. Identify the evidence file that supports the claim. Include successful cases as well as rejections. State the limits of the comparison, including deliberately injected faults and any shared model context. Draw conclusions within the scope established by the recorded results.
